# ALBA-APPS
**Aplikasi Keuangan Pondok Pesantren**  
Real-time Buku Besar + Foto Bukti + Offline Mode

**Target User**: < 20 orang (Kepala Keuangan, Staff Kantor, Kantin, Koperasi)  
**Platform**: Mobile Web (PWA) + Offline Support
