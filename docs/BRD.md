# BRD - ALBA-APPS (Business Requirements Document)

**Versi**: 1.0

---

## 1. Tujuan Bisnis
Meningkatkan efisiensi pelaporan keuangan harian di Pondok Pesantren dengan mengganti proses manual menjadi digital real-time.

---

## 2. Proses Bisnis Saat Ini vs Target

| Aspek | Saat Ini (Manual) | Target (ALBA-APPS) |
|-------|-------------------|--------------------|
| Input Transaksi | Tulis tangan di buku | Input di HP + foto |
| Saldo | Dihitung manual | Otomatis real-time |
| Laporan | Ditulis ulang setiap hari | Otomatis + export |
| Sinkronisasi | Tidak real-time | Real-time + offline |
| Pencarian data | Manual (lama) | Search + filter cepat |
| Bukti transaksi | Kertas/foto terpisah | Langsung attach di transaksi |

---

## 3. Unit yang Dicakup
1. **Kantor Keuangan** (pusat)
2. **Kantin**
3. **Koperasi**

Setiap unit bisa input sendiri, Kepala Keuangan melihat semua secara real-time.

---

## 4. Key Performance Indicator (KPI)
- Waktu membuat laporan harian: dari **2-3 jam** → **< 15 menit**
- Data tersedia real-time (bukan harian)
- Semua transaksi memiliki foto bukti (target 100%)
- Bisa akses data kapan saja (online/offline)
